## Scope
CaseHelper v1: LLM-assisted case notes (no browser automation). Tauri 2 + React + Zustand + SQLite.

## Affected Pages/Routes
- `/` — Dashboard (case list sidebar + main workspace + Todoist panel)
- `/case/:id/notes` — Case notes editor (raw input + LLM draft preview)
- `/case/:id/plan` — Case plan view (plan items, v1.1 scheduling)
- `/settings` — LLM provider + redaction list settings
- `/archive` — Archive search (FTS5)

## Key Interactions to Verify

### Case Notes Flow
1. Select a case from sidebar → main workspace shows that case's notes tab
2. Type raw observations in the input textarea
3. Toggle anonymize switch (in tab's top bar) — verified before drafting
4. Click "Draft" button → "Drafting..." placeholder shown, raw input dimmed
5. LLM returns draft → draft appears in preview pane, editable
6. Copy draft → paste into legacy app manually
7. Draft fails → error message "Draft failed. Check your connection or try again." + retry button, raw input preserved

### Draft Validation
- Click "Draft" with empty textarea → inline error "Please enter your observations before drafting."
- Click "Draft" with whitespace-only → same validation error

### Case Switching
- Switch case with unsaved changes → prompt: "You have unsaved changes in Case A. Save or Discard?"
- Save → immediate save, switch happens
- Discard → changes lost, switch happens
- Cancel → stay on current case

### Archive Search
- Type in search bar, press Enter → FTS5 results shown
- Empty query + Enter → all active cases returned
- No results → "No cases match your search"

### Settings
- Change LLM provider → endpoint/model fields update accordingly
- Enter API key → masked input
- Save → spinner while saving, "Settings saved" on success
- Save fails → "Save failed" + error message

### Todoist Panel
- Panel visible on right edge (desktop ≥1024px)
- Collapse/expand via toggle button
- Shows tasks tagged to selected case
- Empty case → "No tasks for this case"

### Empty States
- No cases → "Welcome to CaseHelper" + "Add first case" button
- No Todoist tasks → "No tasks for this case" in panel

### Error States
- LLM failure → error in draft pane with retry
- Save failure → error message with retry
- Todoist sync failure → "Sync failed" indicator in panel
- Load cases failure → "Failed to load cases" + retry button

## Edge Cases
- 47-character case name — truncated in sidebar list, full name in tooltip
- Very long raw notes input — textarea scrolls, no truncation
- Rapid case switching — unsaved prompt appears each time
- Draft while LLM is still drafting — disable "Draft" button until response received
- Settings API key with special characters — masked properly

## Critical Paths
1. Case note: raw input → draft → copy to legacy app
2. Settings: change LLM config → save → verify saved
3. Case switching: select case → load notes + plan from cache
4. Archive search: query → FTS5 → results displayed

## LLM Quality (deferred to v1.1)
No eval suite in v1. LLM prompt quality verified manually by social worker during use.
